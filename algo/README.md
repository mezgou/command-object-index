# Алгоритмы платформы

Один алгоритм — один Python-модуль в этой папке. Его единственная обязательная функция:

```python
def search(query: str, blocks: list[dict]) -> list[dict]:
    ...
```

Она принимает строку запроса и список смысловых блоков. У каждого блока есть `index` (целое число), `text` и, возможно, `actions` и `objects`.

Функция возвращает ранжированный список словарей **строго** такого вида:

```python
{
    'index': 7,              # индекс исходного смыслового блока
    'text': 'включи кухонный свет',  # конкретная сыгравшая формулировка
    'score': 0.94,           # число от 0 до 1; больше — лучше
}
```

Платформа проверяет этот контракт перед отправкой данных в интерфейс. Общие утилиты находятся в [shared.py](shared.py). После создания модуля добавьте одну запись в [config.py](config.py): `id`, `name`, `description`, `module` и `function`. `main.py` менять не нужно.

## Нормализация

[normalization.py](normalization.py) приводит запрос и формы каталога к одному виду: исправляет английскую раскладку, ё, дефисы, растянутые буквы, выбрасывает слова-паразиты, числа и время, схлопывает повторы. `normalize_text(text)` возвращает нормализованный `text`, список `tokens`, флаг `negated` (в запросе есть «не») и для объяснения — `layout_fixed` и `removed`.

```python
>>> normalize_text('Алиса, сделай cdtn на кухне ярче пожалуйста').text
'сделай свет на кухне ярче'
```

Нормализуйте одной функцией и запрос, и формы — иначе стороны будут сравниваться в разном виде. Пример использования — [levenshtein_normalized.py](levenshtein_normalized.py): тот же Левенштейн, что и `levenshtein-combinations`, но после нормализации.
