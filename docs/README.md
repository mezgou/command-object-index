# MVP: индекс команд

Первая версия ищет кандидатов в одном списке полных текстовых команд. Она не запускает команды и не использует языковую или визуальную модель.

![Схема нулевого MVP](Нулевой%20MVP.svg)

## Как пользоваться

Из корня репозитория запустите:

```bash
docker compose up --build
```

Откройте [localhost:8080](http://localhost:8080). Для остановки нажмите `Ctrl+C` или выполните `docker compose down`. Команды сохраняются в Docker volume `command-data` и переживают перезапуск и `docker compose down` (но не удаление volume).

Добавьте команды вручную или загрузите пример из 18 команд. Загрузка примера **заменяет** текущий список; для неё и очистки предусмотрено подтверждение. Вводите запрос — список пересчитывается после каждого изменения. Команды можно удалять по одной.

## Как работает поиск

Перед сравнением текст приводится к нижнему регистру, пробелы по краям удаляются, последовательности пробельных символов заменяются одним пробелом. Расстояние Левенштейна — минимальное число вставок, удалений и замен символов, необходимых для превращения запроса в команду. Близость вычисляется как `max(0, 1 − расстояние / длина команды)`; длина считается после нормализации. Кандидаты упорядочены по убыванию точной близости, затем по тексту. Зелёная рамка означает близость не меньше 80%. При пустом запросе список показывается без ранжирования и оценок.

Это сравнение написания, не смысла: например, «включи» и «выключи» могут оказаться рядом. Результат требует проверки человеком.

## Устройство

Frontend обслуживается nginx, который перенаправляет запросы `/api/` в Python backend. Данные хранятся в SQLite внутри volume. Алгоритм находится в `backend/app/search.py`. Backend не требует сторонних Python-зависимостей.

Запуск тестов алгоритма из корня репозитория:

```bash
python3 -m unittest discover -s backend/tests
```
