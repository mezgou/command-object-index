# Индекс мультимодальных команд и объектов

Детерминированный движок быстрого поиска кандидатов и нормализации команд с защитой от опасных коллизий (Fail-Safe Policy).

Система спроектирована как легковесный фильтр первого уровня (Fast-Path) перед тяжелыми языковыми или визуальными моделями (LLM/VLA).

---

## 1. Назначение файлов проекта

### Директория `data/`
* **`vocabulary.json`** — эталонный словарь системы. Содержит перечень канонических сущностей (действия `actions`, объекты `targets`) и списки допустимых синонимов и словоформ.
* **`dataset.json`** — верификационный датасет из 864 сценариев. Включает запросы с прямым порядком слов (`exact`), перестановками (`inverted`) и синтетическими опечатками с расстоянием Дамерау — Левенштейна $k = 1$ (`typo`).

### Директория `src/`
* **`distance.py`** — алгоритмическое ядро. Реализует расчет расстояния Дамерау — Левенштейна с поддержкой перестановок соседних символов (транспозиций) для эффективной обработки опечаток.
* **`matcher.py`** — основной модуль (`CommandMatcher`):
  - Пословный разбор и сопоставление токенов с кэшем $O(1)$;
  - Извлечение слотов (`action`, `target`) без привязки к порядку слов;
  - Детекция неоднозначности: при наличии двух равноудаленных кандидатов из разных классов возвращает статус `AMBIGUOUS_REJECT`;
* **`evaluate.py`** — инструмент бенчмаркинга. Прогоняет `dataset.json`, замеряет задержку исполнения и рассчитывает статистику точности и безопасных отказов.

## 2. Результаты тестирования и метрики

Бенчмарк выполнен на контрольной выборке из 864 запросов:

* **Размер тестовой выборки:** 864 запроса
* **Средняя задержка обработки:** 0.078 мс / запрос

### Распределение результатов

| Категория | Объем | Успешно (Success) | Безопасный отказ (Reject) | Точность (Accuracy) |
|---|---|---|---|---|
| `exact` (прямой порядок) | 288 | 288 | 0 | 100.0% |
| `inverted` (перестановки) | 288 | 288 | 0 | 100.0% |
| `typo` (опечатки dist=1) | 287 | 280 | 7 | 97.56% |
| **Итого** | **864** | **856** | **7** (0.81%) | **99.07%** |

*(Оставшийся 1 запрос в выборке `typo` представляет собой артефакт генерации, где удаление буквы в слове «выключи» совпало с валидным словарным действием «включи»).*

### Анализ пограничных случаев (Fallback Rate = 0.81%)
7 запросов категории `typo` (например, `ыключи`, `врыуби`, `ыруби`) находятся на строго равном посимвольном расстоянии ($dist = 1$) одновременно от взаимоисключающих действий (`turn_on` и `turn_off`). 
Вместо недопустимого слепого выбора противоположного действия движок детерминированно фиксирует коллизию и возвращает статус `AMBIGUOUS_REJECT`, предотвращая несанкционированное срабатывание.
